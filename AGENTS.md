# AGENTS.md

OfferFlow is a personal project independently developed by Jiaying Ni.

The project follows a local-first principle. User data should be stored and handled locally by default unless a future product decision explicitly changes this direction.

Real company applications, essays, resumes, interview records, personal notes, and other private job search materials must never be committed to GitHub.

Public demos must use fictional, synthetic, or properly anonymized data only.

Before implementing any new feature, check the product requirements and data model in the `docs/` directory.

During the current phase, do not add complex AI agents, authentication, multi-user support, cloud sync, or automatic job application submission features unless Jiaying Ni explicitly changes the project scope.
