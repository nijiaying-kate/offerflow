# OfferFlow

## A Local-First Job Search Management System

Status: In Development

OfferFlow is a local-first job search management system for tracking companies, job opportunities, applications, deadlines, tailored documents, interviews, and weekly reviews.

Current phase: Product Definition and MVP Design

The concrete technology stack has not been finalized yet. Architecture, data model, and implementation choices will be defined after the product requirements and MVP scope are reviewed.
